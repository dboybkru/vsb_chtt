# ВСБ39

Веб-прототип для компании **ВСБ39 - Ваша Система Безопасности**.

## Что внутри

- Многостраничный сайт: `/`, `/catalog`, `/prices`, `/estimate`, `/about`, `/admin`.
- Каталог оборудования с поиском, похожими товарами, пагинацией и расширенными фильтрами.
- Админка для настроек ИИ, звонков, ботов, SEO, загрузки прайсов и ручного добавления оборудования.
- Парсинг XLSX/XLS/CSV/JSON прайсов, включая нестандартные строки заголовков.
- Извлечение нескольких типов цен: розница, инсталлятор, опт, крупный опт, партнёрская.
- Извлечение встроенных фото из `.xlsx` через `xl/media` и drawing anchors.
- Локальная база на IndexedDB: каталог и смета сохраняются после перезагрузки.
- SEO-слой: динамические title/description, canonical и JSON-LD LocalBusiness.

## Запуск

```bash
npm install
npm run dev -- --port 5174
```

Сайт: `http://127.0.0.1:5174`

## Проверка

```bash
npm run build
```

## Важный технический долг

Парсинг прайсов пока работает в браузере и использует `xlsx` + `jszip`. Это удобно для прототипа, но увеличивает frontend-бандл. Кроме того, у `xlsx` есть известные audit-предупреждения без доступного исправления. Для продакшена парсинг прайсов, хранение API-ключей и вызовы VseGPT нужно вынести на backend.
